It also acts as a user guide for API consumers on how to call the APIs in your custom applications. The Trouble Ticketing Management is a REST interface that lets a third-party application to consume web services to retrieve trouble ticket, create trouble ticket, modify trouble ticket status, add trouble ticket work information etc. The operation process and related technical specification of the Trouble Ticketing Management follows MEF & TM Forum standard, which is based on the following MEF & TM Forum documents: MEF 55 - Lifecycle Service Orchestration (LSO Sonata Trouble Ticketing API Project) TMF621 - Trouble_Ticket_API_REST_Specification , release 19.0.1 Getting Started We were using WSO2 API gateway, and we had migrated to TYK in 2024. Please refer to https://wiki.pccwglobal.com/pages/viewpage.action?spaceKey=CorporateServices&title=API+Gateway+Migration for the migration detail. 2.1 How to get access to TYK Calling Ticketing API via Internal TYK API gateway requires an Auth0 account . To apply an Auth0 account , you may refer to the s ample ticket : https://consoleconnect.atlassian.net/browse/CSCM-18391 . Please state your system id (name) in the ticket. You will get your cl ient id and client secret token after an Auth0 account is created. Jwt token: Jwt token is needed for all Ticketing API calls. You can obtain a jwt token by using your client ID and client secret token.
