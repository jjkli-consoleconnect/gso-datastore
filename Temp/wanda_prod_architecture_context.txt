5) END-TO-END FLOW (PROD, HIGH CONFIDENCE)
==================================================
1. User posts a message in Slack workspace/channel where Wanda app is installed/subscribed.
2. Slack sends event payload to Wanda ingress endpoint (wanda-adk-slack-webhook).
3. Webhook verifies Slack signature/token and parses event body.
4. Webhook performs auth/user enrichment and event filtering.
5. For eligible events, webhook forwards payload/context to ADK_API_URL (wanda-adk-service-bot).
6. ADK service maps message into app/session context under /apps/wanda_chatbot/users/.../sessions/...
7. ADK service executes /run and may invoke tool endpoints:
   - cable-event-agent-for-webhook
   - remedy-api-for-webhook
   - document-agent-for-webhook
   - ticket-analysis-agent-for-webhook
   - wanda-dlp-service
   - Jira/Confluence APIs
   - BigQuery read/write tables for ticket/cable analytics and training context
8. ADK returns generated answer/tool outputs to caller.
9. Webhook posts or updates response in Slack (directly or via Slack Web API calls using SLACK_BOT_TOKEN).
