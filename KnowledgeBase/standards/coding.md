# Coding Standards

## Language
- TypeScript only
- Strict types
- No `any`

## Complexity
- Target O(n)
- Avoid nested loops >2

## Docs
- JSDoc every function
- Clear param, return types

## Tests
- Jest only
- Unit tests required
- Cover edge cases

## Style
- DRY principle
- No duplicate logic
- Refactor smells fast

## Repo
- `KnowledgeBase/` → guides
- `Temp/` → one-off
- `shared/` → reusable utils
